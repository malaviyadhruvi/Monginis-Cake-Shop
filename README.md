# 🍰 Monginis Cake Shop

Monginis Cake Shop is a **Django-based online cake shop and e-commerce web application**.  
The project allows customers to browse cakes and bakery products, register/login, add products to the cart, place orders, select payment methods, view their profile and order history, and download invoices.

---

## 📌 Project Overview

The **Monginis Cake Shop** provides an online platform for customers to explore and purchase bakery products such as:

- 🎂 Cakes
- 🧁 Pastries
- 🍩 Donuts
- 🍫 Chocolates
- 🍫 Chocolate Bouquets
- 🍪 Brownies
- 🧁 Muffins
- 🎁 Packaged Cakes

The application also includes customer authentication, cart management, order management, payment options, profile management, invoice generation, and a simple chatbot.

---

## 🚀 Features

### 👤 User Authentication
- User Registration
- User Login
- User Logout
- Password Authentication
- User Profile
- Profile Picture / Avatar

### 🍰 Product Management
- View products
- Browse products by category
- Cakes
- Pastries
- Donuts
- Brownies
- Chocolates
- Muffins
- Packaged Cakes
- Chocolate Bouquets

### 🛒 Shopping Cart
- Add products to cart
- Manage cart items
- View cart

### 📦 Order Management
- Place orders
- Enter customer delivery details
- Store order information
- Track order status
- View previous orders

### 💳 Payment
- Cash on Delivery
- QR Code payment option
- Payment information stored with orders

### 🧾 Invoice
- Generate PDF invoice
- Download invoice
- Invoice contains:
  - Order ID
  - Customer name
  - Product name
  - Quantity
  - Product price
  - Total amount
  - Delivery information

### 🤖 Chatbot
- Simple customer support chatbot
- Provides information about:
  - Products
  - Orders
  - Delivery
  - Store location
  - Product prices

### 👨‍💼 Admin Panel
- Django Admin Panel
- Manage products
- Manage categories
- Manage orders
- Manage payments
- Manage customers
- Manage bakery product categories
